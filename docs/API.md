# UnderRailWorks API reference

Generated by `tools/apidoc/apidoc.py` from the source comments (namespace `UnderRailWorks`). The guide is UnderRailWorks.md. Parts marked **Preview** aren't covered by the API version yet: they may change in any release (docs/Versioning.md).

## Interface: which to use

Use the game's own windows where one fits: they are right at every resolution and interface size. Rules: UI.md.

| You want | Use | The game's window |
|---|---|---|
| a line of text (a name) | `Ui.Ask` | the save-name popup |
| a number in a range (how many) | `Ui.AskNumber` | the split-stack popup |
| yes or no | `Ui.Confirm` | the message box |
| one of a few answers | `Ui.Choose` | the message box |
| a choice in a conversation | `Dialogs.Define` / `Dialogs.Patch` | the dialog window |
| a short message over a character | `Notify.Over` / `Notify.OverPlayer` | floating text |
| a panel that stays open (a list, a ledger) | `Ui.Window` + `UiRows`, `Ui.List`... | (Works' own; fixed title bar: check other sizes) |
| a line of text on the HUD | `HudText` | (Works' own) |

## Character  _(class, Catalogue.cs)_

- `string Blueprint` — Its blueprint path, matched by name among the creature blueprints (null: no match). See World.BlueprintFor. A character Works spawned or placed: the blueprint it was made from.
- `bool IsTakingTurn` — In combat: this character's turn now.
- `bool Attack(Character target)` — An attack on target with what it holds, as the player's click (the game checks AP, range and line of fire, and refuses with its own message). In a fight only on its turn. False: it can't attack now.
- `bool EndTurn()` — Ends its combat turn (as the player's End Turn: leftover AP carries over up to 10). False: not its turn.
- `bool MoveTo(int x, int y)` — Walks to tile x, y in its area (pathfinding, its speed; it may stop short if the way is blocked). False when it can't take orders (no movement, not on a map) or the tile is outside the area or not floor. In turn-based combat only on its own turn (the whole zone is turn-based: everyone with an AI is in the turn order), spending movement points then AP as the player's walk does (it stops when they run out).
- `bool WalkTo(int x, int y)` — As MoveTo, but it keeps going: a walk the game cuts short (another character in the way: the walk step stops when two bodies' footprints meet, and only the player's clicks or an AI would order it again) is ordered again from where it stopped, a few times, until it's there. For characters a mod drives (CharacterControl).
- `bool TeleportTo(int x, int y)` — Puts it on tile x, y of its area at once (no walking, as the game's scripts move characters between scenes).
- `DefenseStats Defense`
- `bool UsingSecondaryWeapon` — In its secondary weapon set now (the game's swap: X). SwitchWeapons() swaps as the key does.
- `void SwitchWeapons()`
- `int Initiative` — Its initiative (efk.Offense ay(): what StatBonus.Initiative changes).
- `bool RemoveFromWorld()` **(preview)** — Takes it out of the world now (as the game removes a character: c5x.w(), an()). Not the player.
- `bool ReplaceSheet(string path)` **(preview)** — Swaps in the sheet from a .char file (its items, XP, skills, level...) in place: the same body, where it stands, its health kept. For a character from SpawnFromCharacterFile (not the player: for the player the HUD's portrait and some views stayed on the old sheet; build a new body and MakePlayer instead). Cheaper than a new body. False: not such a character, or the file has no sheet.
- `bool HasPlayerSheet` **(preview)** — It has a whole player sheet (the player, or a character from SpawnFromCharacterFile).
- `bool ExportTo(string path)` **(preview)** — Writes its sheet as it is now to a .char file (the game's export format; a new game's Import reads it). False: it has no player sheet.
- `bool ExportTo(string path, DateTime made)` **(preview)** — With the date the file says it was made (the import dialog shows it): a fixed one gives the same bytes for the same sheet, to tell whether it changed.
- `string EntityId` **(preview)** — The game's own id for this character: kept in saves, so a loaded copy of the save has the same one (characters mods spawn get a new one each time they're spawned).
- `int Facing` **(preview)** — Which way it faces: 0 north, 1 north-east ... 7 north-west (map directions).
- `Point? WalkTarget` **(preview)** — Where it is walking to (the tile of its current walk order), or null (not walking somewhere).
- `bool IsWalking` **(preview)** — It has a walk order (going somewhere or following someone).
- `bool UseObject(string entityId)` **(preview)** — Walks to the object with that EntityId (a door, lever, container, computer...) and uses it, as the player's click does. False: no such object here, or it can't be used.
- `bool TalkTo(Character npc)` **(preview)** — Talks to npc as the player's click does (walks there, opens its conversation; j7.a). For the player: the ordinary conversation window. False: either can't talk.
- `bool UseAbility(string abilityId, string itemId, object target)` **(preview)** — Uses an ability (a psi power, a feat's ability, an item's use: a grenade thrown, a hypo injected; a toggle such as stealth) as this character, as the game's own AI does (cp.b / cp.a: walking into range, AP, cooldowns, the character's own skills). abilityId: PlayerOrder.AbilityId (the capability's type); itemId: the item in its bag or gear (PlayerOrder.ItemId; matched by id, else by the same kind of item), null for none; target: a Character, a Point (a tile), or null (itself). False: no such ability or item, or not usable now.
- `bool SwapWeapons()` **(preview)** — Swaps primary and secondary weapon (the X key: dcu.k()).
- `bool Reload()` — Reloads the weapon in hand from its bag, as the AI does (d3k.a: ammo or a battery).
- `bool TakeExitAt(int x, int y)` **(preview)** — Walks to the zone exit on tile x, y and takes it (as the player's click on an exit). The game then changes zone: for everyone, as when the player leaves. False: no exit there.
- `bool PlaceAt(Vector3 at, int facing = -1)` **(preview)** — Puts it exactly there (map tiles, fractional allowed) at once, facing that way (-1: as it is).
- `bool SetStock(IEnumerable<Item> items)` **(preview)** — Replaces a merchant's stock with these items.
- `bool IsPlayer`
- `bool IsHostile` — Hostile or unfriendly to the player, not passive (red and orange outlines).
- `Vector3 Position` — Map position (tiles; fractional while moving).
- `void Follow(Character leader, int distance = 3)` — Keeps near leader (within distance tiles) out of combat; null stops it. For spawned allies, pets, escorts.
- `void Follow(Character leader, int distance, bool travels)` — travels: a spawned follower of the player comes along to other zones (spawned again next to the player, with its health; GameEvents.FollowerArrived gives the new character). Never saved: a loaded game has none.
- `void StopFollowing()`
- `bool IsFollowing`
- `Area Area`
- `Rectangle? ScreenBounds` — Where it was drawn on screen in the last frame (interface units, as Ui positions), or null (not drawn).
- `Attitude Attitude`
- `Color OutlineColor` — The colour holding Tab outlines it in (gold for the player, sandy brown if passive, else by attitude).
- `bool IsCharacter` — A character (has character data), not a placed object such as a turret's base or a prop.
- `bool CanTalk` — It can be talked to (has the dialog aspect the game's Talk uses).
- `string Id`
- `string Key` — A stable key for remembering this character: its id, or its name when it has none (characters spawned from a blueprint have no template id).
- `string Name`
- `int Level`
- `string Faction`
- `bool Passive`
- `bool IsDead`
- `bool IsInCombat` — Its own "in combat" flag (efk.IsInCombat: a timer set by hostility, running down per turn). Note: in a fight the whole zone is turn-based and every character with an AI is in the turn order (crp.ahx registers each one when it becomes active), flag or not.
- `void Kill()`
- `bool CanSee(Character other)` — Its AI can see where other stands now: the game's own field of view (walls and all), as enemies notice the player (bm6.a(tile): in a fight the tiles the fight worked out it sees, else its vision's visible points). False for one without an AI, or in another area.
- `float SightRange` — How far it sees (tiles): its sheet's SightRange, what its AI's vision uses.
- `bool HasNoticed(Character other)` — Its AI has detected other (the game's own awareness: unaware -> suspicious -> detected; bm6.e). What makes characters join a fight. False for one without an AI.
- `float Health`
- `float MaxHealth`
- `IDictionary<string, Resistance> Resistances` — Damage threshold (flat, subtracted first) and resistance (percent) per damage type, as combat uses them (efk.Defense.af()[type]: du2.a() threshold, du2.c() resistance fraction). Keys: Mechanical, Heat, Cold, Electricity, Acid, Energy, Bio (the names Combat's damage parts use).
- `int Detection` — How well it notices sneaking characters (compared with their Stealth).
- `int Ability(string name)` — Base abilities by name (Strength, Dexterity, Agility, Constitution, Perception, Will, Intelligence) and skills by name (Guns, Persuasion, Mercantile...): the value with bonuses, and the base value, which can be set.
- `int BaseAbility(string name)`
- `void SetBaseAbility(string name, int value)`
- `int Skill(string name)`
- `int BaseSkill(string name)`
- `void SetBaseSkill(string name, int value)`
- `IList<string> SkillNames` — The names of its skills (as Skill/SetBaseSkill take them).
- `int SkillPoints` — The player's unspent points (spent on the game's level-up screen): skills, abilities, feats (0 for others).
- `int AbilityPoints`
- `int FeatPoints`
- `IList<string> Feats`
- `bool HasFeat(string name)` — By display name or key (the game's internal name, or a mod feat's ModFeat.Key).
- `int Experience`
- `void GiveExperience(int amount, string reason = null)` — XP as the game gives it (its notice, level-ups): the player, or a character with a player sheet (amc.a(int, string)).
- `Inventory Inventory`
- `Equipment Equipment` — What it wears and wields; equip and unequip.
- `override string ToString()` — Its personal attitude to the player (overrides its faction's), as the game's scripts set it.
- `Attitude AttitudeToPlayer`
- `Attitude AttitudeTo(Character other)` — How it stands towards another character (its own override for the other's faction, else the faction table), e.g. whether an enemy would fight the player's ally. None for non-characters.
- `void SetAttitudeToFaction(string faction, Attitude attitude)` — Its own attitude to everyone of a faction ("player", "playerNativeAlly", a faction id as Faction shows), whatever the faction table says. None: back to the table.
- `void SetAttitudeToPlayer(Attitude attitude)`
- `bool Say(string text, bool interrupt = true)` — Says a line over its head, as the game's barks do (c0s: floating speech; the game also puts it in the chat log when the player can see the speaker). interrupt: replace what it is saying now. False if it can't speak (no speech aspect: only characters Works placed get one added, game characters keep theirs as saved).
- `IList<StatusEffect> StatusEffects`
- `bool HasStatusEffect(string code)`
- `bool IsMerchant`
- `bool MakeMerchant(string store)` — Makes a placed character a merchant with one of the game's stores (data/Rules/Stores/<name>.store, e.g. "bigbret"), as the game's scripts do (die: the merchant aspect, the store name, a restock). Only characters Works placed (they are never saved); false otherwise.
- `string StoreName` — A merchant's stock (what the barter screen lists on their side), and what they charge the player per item value. The game store it runs ("bigbret": data/rules/stores/<name>.store), or null.
- `IList<Item> Stock`
- `float Markup`
- `Variables Variables` — Its own variables (the game's per-character CustomProperties, saved with it).
